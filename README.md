## 📊 Pandas Learning Journey

This repository contains my hands-on practice and learning of **Pandas**, a powerful Python library for data analysis and manipulation. I’ve worked with real datasets (`empData.csv`, `customer.csv`, and `spotify.csv`) to understand core concepts like DataFrames, Series, indexing, grouping, aggregation, and preprocessing.


## 📌 Key Concepts Covered

- ✅ Reading CSV files into DataFrames
- ✅ Creating and manipulating Series
- ✅ Indexing and selecting data using `.iloc[]` and `.loc[]`
- ✅ Conditional selections and filters
- ✅ Handling missing values with `.fillna()` and `.dropna()`
- ✅ Grouping and aggregating data with `.groupby()` and `.agg()`
- ✅ Using `.apply()` for custom column creation
- ✅ Checking for duplicates
- ✅ Converting data types using `pd.to_datetime()`
- ✅ Basic data cleaning and preprocessing

## 📂 Datasets Used

- `empData.csv`: Contains employee data (salary, performance scores, etc.)
- `customer.csv`: Marketing campaign data (age, ad spend, campaign type)
- `spotify.csv`: Music dataset (songs, popularity, energy, loudness, etc.)
